# .claude/rules

Sengaja kosong untuk sekarang.

Folder ini disediakan untuk aturan tambahan yang lebih sempit dari
[`CLAUDE.md`](../../CLAUDE.md) — misalnya aturan khusus per-area (`outbound-queue.md`,
`knowledge-indexing.md`) kalau nanti sebuah area punya kesepakatan yang terlalu detail untuk
konstitusi utama.

Aturan yang mengikat seluruh repo tetap di `CLAUDE.md`. Jangan pecah aturan inti ke sini —
satu sumber kebenaran lebih baik daripada dua yang bisa saling bertentangan.
